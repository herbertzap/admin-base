# 📊 MITATC - Resumen Ejecutivo del Proyecto

## 🎯 Visión General

**MITATC** es un sistema web integral desarrollado para la gestión de contenedores aduaneros, cumpliendo con la normativa chilena (Resolución exenta Nº 5660 del 20 de diciembre del 2018) y con integración completa a la API HERMES de la Aduana de Chile.
